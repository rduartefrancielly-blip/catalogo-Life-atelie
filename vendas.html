Colar vendas da live

Cole as mensagens do WhatsApp (uma ou várias clientes). O sistema lê nome, telefone, CPF, endereço, produto, cor, tag e pagamento, e mostra tudo para você conferir antes de lançar. Separe cada cliente com uma linha em branco.

Estoque

É o mesmo estoque do catálogo. Cada venda já tira daqui. Use − e + para ajustar (fica registrado no histórico) ou digite a quantidade certa. Para atualizar muita coisa de uma vez, use a lista em PDF no painel do catálogo.

Histórico do estoque

Toda entrada, saída, ajuste e venda fica registrada, com data, quantidade e motivo.

    Formato do texto da venda

    É o texto do botão "Copiar" de cada venda. Use estas palavras entre chaves: {cliente} {documento} {telefone} {email} {endereco} {itens} {total} {pagamento} {tags} {observacao} {numero} {data}. A linha cujos dados estiverem vazios some sozinha. Fica salvo neste aparelho.

    Esta conta

    Exportar vendas para o Bling

    Gera uma planilha das vendas do período (sem as canceladas) para conferir e importar no Bling. Teste com uma venda antes de levar várias: a ordem das colunas ainda não foi conferida com a importação do Bling.

    Clientes

    Planilha com todas as clientes cadastradas (nome, CPF, telefone, endereço).

    Lançar uma venda de cada vez

    Na aba Vendas, o botão Copiar de cada venda copia o pedido pronto para colar no Bling. O botão Marcar no Bling guarda quais já foram lançadas.

    Ligação direta com o Bling (API)

    Ainda não está ativa. Para ligar, é preciso criar um aplicativo no Bling e guardar a chave em um lugar seguro do servidor. Por enquanto use a planilha acima.

    Cópia de segurança

    Baixa um arquivo com tudo (produtos, clientes, vendas, tags e histórico). Guarde fora do computador. O plano gratuito do banco não faz cópia automática, então vale repetir de tempos em tempos.

    Os dados ficam guardados no banco online, iguais em todos os aparelhos.
